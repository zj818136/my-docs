# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布：改一次文档、推一次代码，网站就自动更新，全程不需要手工打包和上传。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容，纯文本、便于版本管理 |
| MkDocs Material | 将 Markdown 构建成带导航和主题的静态网站 |
| GitHub Actions | 自动执行依赖安装、构建和发布 |
| GitHub Pages | 托管 `site/` 构建产物并提供公网访问地址 |

## 我的理解

这四个工具像一条流水线上的四个工位：Markdown 负责"写"，MkDocs 负责"排版"，Actions 负责"跑腿"，Pages 负责"开门"。真正把它们串起来的是两份配置——`mkdocs.yml` 决定站点长什么样、包含哪些页面，`deploy.yml` 决定什么时候、以什么方式发布。少任何一环，"改文档 → 网站更新"都不成立。
