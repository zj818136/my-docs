# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

| 项目 | 说明 |
| --- | --- |
| 请求方法 | GET |
| 请求路径 | `/api/docs` |
| 功能 | 返回文档条目列表 |

### 请求示例

```bash
curl -X GET https://example.com/api/docs
```

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

### 我的说明

本次作业不要求实现后端，这一页用于练习"如何用 Markdown 描述接口"。我把字段整理成表格，因为表格比成段文字更容易快速对照；示例用可直接复制的 JSON，方便读者拿去做联调桩数据。真实项目里还会补上错误码和鉴权说明，这里先留出结构。
